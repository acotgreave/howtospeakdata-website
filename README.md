# howtospeakdata.com

Andy Cotgreave's keynote-speaker site. Static site built with [Astro](https://astro.build), hosted on GitHub Pages.

## Everyday edits

| To change… | Edit |
|---|---|
| Any copy, quotes, stats, topics, links, booking URL | `src/data/site.yaml` |
| Photos | Replace the file in `src/assets/photos/` (keep the name, or update it in `site.yaml`) |
| "Spoken at" logos | Add to `src/assets/logos/`, then list it under `spoken_at` in `site.yaml` |
| Book covers | Add to `src/assets/books/`, set `cover:` in `site.yaml` |
| One-sheet PDF / bio pack | Put in `public/downloads/`, set `links.one_sheet` / `links.bio_pack` |
| Colours / fonts | `src/styles/global.css` (tokens at the top) |

Edits can be made directly on github.com (pencil icon) — committing to `main` rebuilds and redeploys in ~2 minutes. A link left as `""` in `site.yaml` hides its button, so nothing dead ever ships.

## Latest content feeds

`.github/workflows/deploy.yml` runs daily (and on every push). It runs `scripts/fetch-feeds.mjs`, which reads the three streams under `content.streams` in `site.yaml`, writes the latest 5 items of each to `src/data/feeds.json`, commits that file if anything changed, and redeploys.

- **The AI Analyst** — YouTube playlist "The AI Analyst?". Add new episodes to that playlist and they appear here.
- **Chart Chat** — the @chartchatlive YouTube channel (Shorts skipped).
- **Newsletter** — Substack RSS.

Each card leads with the latest item as a thumbnail (YouTube videos play in place; the newsletter uses the Substack cover image), then four dated rows. Scheduled YouTube livestreams appear as a **Coming up** row at the top of their card, shown in the visitor's local time. It switches to **Live now** at start time and disappears afterwards; the episode joins the list on the next feed update. Livestream dates are the real air date, not the upload date.

If a feed is down, its previous items are kept and the run shows a warning. Run it by hand from **Actions → Update feeds and deploy → Run workflow**.

**Playlist limit:** YouTube's playlist RSS only shows a playlist's first 15 videos. Once "The AI Analyst?" passes 15 episodes, either set the playlist order to *Date added (newest)* in YouTube Studio, or add a free YouTube Data API key as a repo secret named `YOUTUBE_API_KEY` (Settings → Secrets and variables → Actions) and the script will use it automatically.

## Local development

Needs Node 24 (`.nvmrc`).

```bash
npm install
npm run feeds   # optional: refresh feeds.json
npm run dev     # http://localhost:4321
npm run build   # production build into dist/
```

## First-time GitHub setup

1. Create an empty repo on GitHub and push this folder to `main`.
2. Repo **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. The first push deploys to `https://<user>.github.io/<repo>/`.

## Moving howtospeakdata.com here (when ready)

1. Repo **Settings → Pages → Custom domain**: `howtospeakdata.com`, then tick **Enforce HTTPS** once offered.
2. At your DNS provider, change **only** the web records:
   - `A` records for `@` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME` for `www` → `<user>.github.io`
3. **Do not touch `MX`, `TXT` (SPF/DKIM/DMARC) records** — they carry andy@howtospeakdata.com email.
4. Verify the domain under your GitHub account (Settings → Pages → Verified domains) to prevent takeover.

No code change is needed: the workflow picks up the domain and base path automatically.

## Structure

```
src/data/site.yaml        all content
src/data/feeds.json       auto-generated by the feeds script — don't hand-edit
src/pages/index.astro     homepage (add new pages as src/pages/speaking.astro etc.)
src/layouts/Base.astro    <head>, SEO tags, header + footer shared by every page
src/components/           Header, Footer
src/assets/               images (optimised at build time)
public/                   files served as-is (favicon, downloads)
scripts/fetch-feeds.mjs   feed fetcher
```
